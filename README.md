## 🚀 Installation

1. Clonez le projet ou téléchargez les fichiers
2. Ouvrez `index.html` dans un navigateur
3. Le portfolio est prêt à l'emploi !

### Réception des messages du formulaire

Le formulaire envoie les messages à `oabou536@gmail.com` avec FormSubmit. Lors du premier envoi depuis le site publié, confirmez l'adresse en cliquant sur le lien reçu par email. Après cette activation, les nouveaux messages sont transmis à cette boîte mail. Le formulaire nécessite une connexion Internet et ne doit pas être utilisé avec des identifiants Gmail ou un mot de passe d'application dans le code.

```bash
# Pour un serveur local (optionnel)
npx serve .
# ou
python -m http.server 8000
```
